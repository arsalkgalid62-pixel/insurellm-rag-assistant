# Knowledge base

Synthetic **Insurellm** corporate documents used for RAG demos (LLM Engineering Week 5).

| Folder | Contents |
|--------|----------|
| `company/` | Company profile, careers, culture |
| `products/` | Product sheets (Carllm, Healthllm, …) |
| `employees/` | Employee profiles |
| `contracts/` | Client contract summaries |

Add or edit `.md` files here, then rebuild the index:

```bash
python scripts/ingest.py
```
